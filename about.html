About this kit

Every file here is sent to the browser exactly as written. There is no node_modules, no bundler and no compile step between your editor and the page.

Each page is its own HTML file, so a new page is a copied file and a new link. Start with index.html, then assets/js/main.js, which wires the form, the list and storage together.

The VanillaFirst Backend Kit serves the same bookmarks as a JSON API, and the Full-Stack Kit builds the same list with PHP pages and SQLite, so the data lives on a server instead of in one browser. Compare them to see exactly what a back end adds.

Plain HTML, CSS and JavaScript. Zero build steps.
